In order to run all of the code you need at least MATLAB R2026b

Problem1.m:
In problem 1 there is a variable "n" and this variable can be any number from 1-10
This number represents the image in the test data it is restoring.

When you choose a number "n" it will output the following when you run it:
In the figure window:
- Histogram of the red channel
- Image of the red channel
- Histogram of the green channel
- Image of the green channel
- Histogram of the blue channel
- Image of the blue channel
- The histogram of the manipulated channel after resoration
- The fully restored image

In the command window:
- The channel that the detect_tampering function believes was tampered
- The confidence score

Problem2.m:
In this script you just press run and the resulting images will print out into the file 'Test Results/Problem2'.
You can then navigate to that folder to see the resulting images.
